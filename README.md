## BagSorter - WoW TBC Classic Addon

This repository now includes **BagSorter**, a World of Warcraft: The Burning Crusade Classic Anniversary Edition addon for sorting inventory bags.

### Features
- Right-click bag sorting with Ctrl+Right-click
- Sort by category (Quest, Armor/Weapon, Food/Drink, Materials)
- Sort by price (vendor value)
- Sort alphabetically
- Slash commands for quick access

### Installation
See the [BagSorter README](BagSorter/README.md) for detailed installation and usage instructions.

### Quick Start
1. Copy the `BagSorter` folder to your WoW `_classic_/Interface/AddOns/` directory
2. Restart WoW or type `/reload`
3. Ctrl+Right-click on any bag to sort!
